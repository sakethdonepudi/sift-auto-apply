## Detailed description

SIFT is a local-first assistant for people who want a more focused LinkedIn Easy Apply workflow.

Choose a target role and location, save a PDF resume and truthful recurring answers, then start a run from the extension. SIFT opens a visible LinkedIn jobs tab, scans Easy Apply results, rejects titles or locations outside the brief, fills supported application fields, and submits only after LinkedIn exposes its Submit Application action.

What SIFT includes:

- precise role and location filtering;
- worldwide, country, region, city, and remote searches;
- user-controlled submission and scan limits;
- local PDF resume and answer storage;
- reusable custom answers for recurring questions;
- visible scanned, submitted, and skipped counts;
- confirmed submissions before a job is counted;
- duplicate detection and persistent job history;
- safe skips for unknown required questions;
- automatic stop on LinkedIn security checks;
- an immediate Stop control.

SIFT is user-started and runs in a visible tab. It has no developer server, analytics, advertising, data sale, or remote code. Saved profile data stays in Chrome extension storage on the user's device and is sent only to LinkedIn application forms selected by the user during a run.

LinkedIn can change its interface and may limit automated activity. SIFT does not bypass CAPTCHAs or security checks and cannot guarantee that every employer form is supported. Users are responsible for truthful answers and compliance with LinkedIn's terms and applicable rules.

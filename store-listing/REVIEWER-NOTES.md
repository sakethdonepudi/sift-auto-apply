# Reviewer notes

SIFT has one purpose: assist a user-started LinkedIn Easy Apply run with precise job matching and saved answers.

## Test flow

1. Install the extension and pin it.
2. Open Setup, enter a target role/location, add a PDF resume, and save.
3. Sign in to LinkedIn in the browser.
4. Open the popup and press **Start run**.
5. SIFT opens a visible LinkedIn Easy Apply search and displays progress in the popup.
6. Press **Stop safely** at any time to end the run.

SIFT does not request LinkedIn credentials, run invisibly, bypass security checks, or execute remotely hosted code. Unknown required questions cause that job to be skipped. The reviewer can use an application limit of 1 for testing.

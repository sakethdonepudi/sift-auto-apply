Privacy Policy

Effective September 26, 2026

SIFT — Easy Apply Assistant is a user-started browser extension that helps a person search for matching LinkedIn jobs and complete LinkedIn Easy Apply forms with answers they save.

Data SIFT handles

SIFT may handle the resume, name, email address, phone number, profile links, location, work authorization, sponsorship status, experience, salary expectation, notice period, custom application answers, target roles, and application history that the user chooses to save.

Where data is stored

This data is stored locally using Chrome extension storage on the user's device. SIFT does not operate a developer server and does not send this data to the developer. When the user starts a run, SIFT inserts selected data into LinkedIn application forms; LinkedIn receives that data under its own terms and privacy policy.

No sale, advertising, or analytics

SIFT does not sell data, use data for advertising, run analytics, use remote code, or transfer user data for credit, lending, or unrelated purposes.

Permissions

SIFT uses local storage to retain setup and run state, alarms to detect stalled runs, and access to LinkedIn job pages to read visible job/application fields and complete Easy Apply steps after the user presses Start.

Retention and deletion

Saved data remains on the user's device until it is cleared or the extension is removed. Users can clear application history from the popup. Removing the extension deletes its extension-local storage.

Security and choices

SIFT does not ask for a LinkedIn password and does not bypass security checks. Users should save only truthful answers, review their setup before a run, and stop a run from the extension popup at any time.

Contact

Questions can be submitted through the SIFT GitHub issue tracker.
